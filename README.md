# 🛡️ VigilPay

## Real-Time UPI Fraud Detection & Security Platform

VigilPay is a cloud-based cybersecurity platform designed to
identify potential UPI payment fraud using QR analysis, VPA
reputation, behavioral analysis, rule-based detection and
real-time risk scoring.

### Core Features

- UPI ID / VPA analysis
- QR code security analysis
- Rule-based fraud detection
- Behavioral anomaly detection
- Risk scoring
- SAFE / SUSPICIOUS / DANGEROUS verdicts
- Real-time security alerts
- Security monitoring dashboard
- Audit logging
- User authentication
- REST API
- PostgreSQL database
- External device integration
- Cloud deployment

### Technology Stack

Frontend:
React + Vite

Backend:
Python + FastAPI

Database:
PostgreSQL

Deployment:
Vercel + Render
